# Ứng dụng Lokito

Một ứng dụng mạng xã hội hiện đại được xây dựng bằng Flutter.

## 🚀 Tính năng nổi bật

- **Giao diện Modern Social**: Phong cách tràn viền, hào quang ánh sáng (Social Spotlight) tối ưu cho năm 2025.
- **Glassmorphism**: Hiệu ứng kính mờ tinh tế trên các thẻ bài viết.
- **Chế độ tối (Dark Mode)**: Hỗ trợ toàn diện và chân thực.
- **Đa ngôn ngữ (L10n)**: Hỗ trợ linh hoạt Tiếng Anh và Tiếng Việt sử dụng Slang.
- **Nguồn cấp tin tức (Feed)**: Luồng cuộn mượt mà với tính năng đăng bài bằng Optimistic UI.

## 🛠 Công nghệ sử dụng

- **Framework**: Flutter (Dart)
- **Quản lý trạng thái (State Management)**: Riverpod
- **Backend**: Supabase (Database & Auth)
- **Lưu trữ hình ảnh**: Cloudinary
- **Điều hướng (Navigation)**: GoRouter
- **Kiến trúc**: Clean Architecture
